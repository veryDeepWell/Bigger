# Проверка интерфейса в браузере

Дата: 1 ноября 2026. Браузер: Microsoft Edge, Windows, окно 1536×912.

Использована локальная копия приложения с подменой Firebase SDK через import map на тестовый адаптер и запретом внешних соединений через CSP connect-src. Реальная база не использовалась.

Проверено через интерфейс:
- Восстановление позиции старше начальной страницы истории, разделитель новых сообщений, локальное сохранение после перезагрузки.
- Добавление входящего сообщения увеличивает счётчик без изменения позиции прокрутки.
- Поиск без текста по автору, PDF и последним семи дням; сброс фильтров; поиск сообщений с кодом и переход к результату.
- Подсветка синтаксиса, номера строк, разворачивание длинного блока и перенос длинной строки.
- Копирование целого блока подтверждено вставкой в тестовый черновик без отправки в реальную базу.
- В Diff видны красные удалённые и зелёные добавленные строки.
- Просмотрщик: открытие, масштаб колёсиком, перетаскивание, переходы вперёд/назад стрелками, подписи, закрытие Escape.
- Картинка скачалась; скачивание code.js дошло до штатного предупреждения Edge, которое не подтверждалось.

Исправлено по результатам:
- Панель просмотрщика перекрывалась шапкой: просмотрщик перенесён в корень body.
- При восстановлении позиции учитывается декодирование изображений с ограниченным ожиданием.
- Имя вложения показывается в результате поиска даже при наличии текста сообщения.

Мобильный браузер и реальные подключения двух пользователей не проверялись.
